# Plantbnb

A tiny Node/TypeScript program for the make.fun bounty "Ridiculous at First Glance, Real by the Second". It writes one startup pitch to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> A subscription that rents out other people's houseplants for parties, so your apartment looks loved and your plants stay alive — Plantbnb, but the hosts never cancel.

Run it with: `node main.ts`
